## 🚀 Featured Projects / Proyectos Destacados

### 🥖 [Panes & Pan – POS, Admin System & Website](https://panesypan.com) · [repo](https://github.com/DjSantech/PanesyPan)
- **EN:** POS and admin system that **replaced the commercial platform** a bakery in Dosquebradas was paying for (TryTiendas), plus its public website. Counter and table sales with mixed payments (cash, Nequi, Daviplata, card), cash-register close with denomination count, inventory with production and waste, real-time dashboard (**Socket.IO**), installable **PWA**, thermal tickets and **DIAN electronic invoicing** (Factus) ready to activate. Security with backend **RBAC**, argon2id, httpOnly cookies, CSRF and Cloudflare WAF; tests with **Vitest, Supertest, Playwright** and axe (WCAG 2.2 AA), CI on **GitHub Actions**. Stack: TypeScript pnpm monorepo, **React 19, Vite, Node.js/Express 5, Zod, MongoDB Atlas** — system on Cloudflare, API on Render.
- **ES:** Sistema POS y administrativo que **reemplazó la plataforma comercial** que pagaba una panadería de Dosquebradas (TryTiendas), más su sitio web público. Venta en mostrador y por mesa con pagos combinados (efectivo, Nequi, Daviplata, tarjeta), cierre de caja con arqueo por denominaciones, inventario con producción y mermas, dashboard en tiempo real (**Socket.IO**), **PWA** instalable, tiquetes térmicos y **facturación electrónica DIAN** (Factus) lista para activar. Seguridad con **RBAC** en el backend, argon2id, cookies httpOnly, CSRF y WAF de Cloudflare; pruebas con **Vitest, Supertest, Playwright** y axe (WCAG 2.2 AA), CI en **GitHub Actions**. Stack: monorepo pnpm en TypeScript, **React 19, Vite, Node.js/Express 5, Zod, MongoDB Atlas** — sistema en Cloudflare, API en Render.

### 🍸 Pasarela Internacional – Nightclub Management System *(private)*
- **EN:** Private management system (PWA) for a nightclub and entertainment venue in Pereira. Stack: TypeScript monorepo with shared **Zod** schemas, **React + Vite + Tailwind** on Cloudflare Pages, **Node.js/Express + Mongoose** API on Render, **MongoDB Atlas** and **Cloudinary**.
- **ES:** Sistema privado de gestión (PWA) para una discoteca y centro de entretenimiento en Pereira. Roles de administrador, barra, meseros (cada uno con su código) y modelos; cuenta abierta por mesa, base de caja y cuadre por mesero, comisiones por escalas, inventario con kardex, ingresos y egresos, reportes y tiquetes térmicos de 58/80 mm. Stack: monorepo TypeScript con esquemas **Zod** compartidos, **React + Vite + Tailwind** en Cloudflare Pages, API **Node.js/Express + Mongoose** en Render, **MongoDB Atlas** y **Cloudinary**.
